Fonts served from this directory
===============================

These files are redistributed with the site rather than loaded from a font
CDN. Both licences below permit that; both also require that the licence
travels with the files, which is what this file is for.

Regenerating
============

Archivo
-------
Source: the npm package @fontsource-variable/archivo@5.3.0 (OFL-1.1), file
files/archivo-latin-standard-normal.woff2 (wght 100-900, wdth 62-125, 90 KB).
Unpack it in its own empty folder. Then, with fontTools + brotli:

  python -m fontTools.varLib.instancer archivo-latin-standard-normal.woff2 wght=400:800 wdth=75:100 -o inst.ttf

  python -m fontTools.subset inst.ttf --flavor=woff2 --output-file=archivo-var.woff2 --layout-features="kern,liga,tnum,case" --unicodes="U+0020-007E,U+00A0-00FF,U+0131,U+0152-0153,U+2013-2014,U+2018-201E,U+2022,U+2026,U+2032-2033,U+2190-2193,U+2197,U+2212,U+20AC,U+2122"

Result: 47,720 bytes. If a weight outside 400-800 or a width outside 75-100%
is ever used in CSS, widen the instancer ranges, or the browser clamps
silently. Ω, µ, ≈ and subscripts are not in the face and fall through to the
symbol families in the font stacks, as they did with Exo 2.

Verify coverage before committing (fontTools: TTFont(path).getBestCmap() must
contain A-Z, a-z, 0-9 and the punctuation above), and check the axes
(TTFont(path)['fvar'].axes).

Google Fonts lesson, kept because it cost a lot to learn: never request text
families combined with Material Symbols in one css2 URL. The combined endpoint
once cut Exo 2 and Playfair Display to a 27-glyph subset with no capitals, and
nothing errors when a glyph is missing.

Material Symbols regenerates the same way it always did -- combined request,
icon_names subset intentional:

  https://fonts.googleapis.com/css2?family=Material+Symbols+Rounded:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200&icon_names=accessibility_new,add,album,arrow_back,bug_report,build_circle,center_focus_strong,chevron_left,chevron_right,close,code,computer,copyright,dark_mode,electric_bolt,emoji_events,fit_screen,flight,fullscreen,fullscreen_exit,gavel,handyman,hub,library_music,light_mode,mail,memory,military_tech,open_in_full,open_in_new,pause,person,photo_camera,photo_library,play_arrow,play_circle,progress_activity,radio_button_checked,refresh,remove,search,settings,speaker,stars,sync,thermostat,upload_file,videocam_off,visibility,visibility_off,zoom_in&display=swap

Adding an icon means adding its name to icon_names here AND re-downloading,
or the new icon renders as its literal ligature text -- the subset will not
contain the glyph.

The @font-face rules that point at these files live in src/styles/index.css.
